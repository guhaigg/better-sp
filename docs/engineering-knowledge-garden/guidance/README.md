# Guidance Artifacts

Guidance briefs are the **compressed downstream handoff** between archived research and everyday planning / implementation.

Use guidance briefs for:
- borrow / avoid summaries from a longer landscape brief
- handing planning skills a small artifact instead of a giant comparison matrix
- keeping the archive retrievable without prompt-stuffing it downstream

Do **not** use guidance briefs for:
- evergreen project memory
- full research history
- raw implementation notes

## Common command

```bash
node skills/engineering-knowledge-garden/scripts/garden.cjs extract-guidance \
  --archive docs/engineering-knowledge-garden/archive/landscapes/2026-04-06-agent-workflow-landscape.md
```
